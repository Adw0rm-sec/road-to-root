OPERATOR,

You have a foothold as 'labuser1' on Hollow Industries' build host.
Run `id`. You're in the 'docker' group. On a box that runs Docker,
that is not a convenience — it is root with extra steps.

The Docker daemon runs as root and listens on a unix socket at
/var/run/docker.sock. Anyone who can write that socket can ask the
daemon to start a container — and a container can mount the host's
entire filesystem and run as root inside it. Mount  /  , chroot into
it, and you are root on the host, flag and all.

OBJECTIVE
  - Escalate from labuser1 to root.
  - Capture the flag:  /root/flag.txt   (only root can read it)

THREE WAYS TO SHOW THE SAME TRUTH
  A  docker run -v /:/host ... chroot /host cat /root/flag.txt
  B  same mount, but write yourself a permanent root shell (SUID bash
     / your SSH key) on the host.
  C  do it WITHOUT the docker client — just curl the socket's HTTP API.

FIRST MOVE
  id ; ls -l /var/run/docker.sock ; docker images

There's a local image called rtr/bb ready to use (this box has no
internet). The real debrief is in targets/docker/WRITEUP.md after
you've had a go.

Good hunting.
